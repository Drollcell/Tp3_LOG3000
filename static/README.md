Module static:
  Description: Regroupe les ressources statiques nécessaires à la 
    présentation et au fonctionnement visuel de l’application
  Contient les fichiers :

    Fichier : style.css
      Description : Définit la présentation visuelle de la calculatrice,
        notamment la mise en page, les couleurs, les dimensions et les
        interactions visuelles des boutons.
      Responsabilités :
        - Centrer la calculatrice dans la fenêtre.
        - Définir l'apparence de l'affichage et des boutons.
        - Différencier visuellement les opérateurs.
        - Fournir un retour visuel lors des interactions.
